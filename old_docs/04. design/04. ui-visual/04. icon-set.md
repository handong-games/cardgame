# 아이콘 세트 가이드

## 개요

이 문서는 게임 내 모든 아이콘의 디자인 규칙을 정의합니다. 현재 이모지 플레이스홀더를 일러스트 스타일 아이콘으로 대체하기 위한 가이드입니다.

---

## 아이콘 디자인 원칙

### 핵심 원칙
```
1. 일관된 스타일: 스토리북 일러스트 스타일 유지
2. 즉각적 인식: 0.5초 내 의미 파악 가능
3. 크기 독립성: 16px~64px에서 모두 인식 가능
4. 색상 구분: 카테고리별 일관된 색상 체계
```

### 스타일 가이드
- **선 두께**: 아이콘 크기의 8-10%
- **모서리**: 약간 둥글게 (완전한 직선 지양)
- **채색**: 단색 + 그림자 (2-3톤)
- **질감**: 수채화 느낌의 부드러운 그라데이션

## 아이콘 생성 마스터 프롬프트

### 기본 템플릿
```
[ICON MASTER PROMPT]
[ICON_SUBJECT] icon, medieval fantasy style,
storybook illustration, hand-painted watercolor texture,
simple bold silhouette, [PRIMARY_COLOR] with [ACCENT],
clear recognizable shape, soft edges,
isolated on transparent background,
game UI icon, 1:1 square format

[NEGATIVE]
3D render, photorealistic, complex details,
modern design, flat vector, gradient mesh,
blurry, low contrast, multiple elements
```

### 카테고리별 수정자

**리소스 아이콘**
```
+Add: glowing effect, precious material feel,
warm highlight, slight sparkle
```

**상태 효과 아이콘**
```
+Add: magical aura, ethereal glow,
clear status indication, symbolic meaning
```

**행동 아이콘**
```
+Add: dynamic pose suggestion, directional clarity,
action implication, immediate recognition
```
