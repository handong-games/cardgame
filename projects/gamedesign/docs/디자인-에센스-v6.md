## 2. 반드시 지켜야 할 감정 축

| 축 | 유지할 감각 | 피해야 할 감각 |
|----|-------------|----------------|
| 분위기 | 아늑함, 몽환, 모험의 설렘, 채도 시프트로 자연스러운 긴장 | 공포, 혐오, 고어, 과잉 우울, 다크 판타지 |
| 캐릭터 | 용기, 결의, 친근함, 귀여운 모험가 에너지 | 성숙 과잉, 냉정함, 영웅 과장 |
| 몬스터 | 위협적이지 않은 귀여운 판타지, 패턴 읽기의 명확성 | 혐오감, 혐오 디테일, 공포 톤, 혼탁함 |
| 프레임/UI | 기능적 안정감, 양피지 통일감, 조용한 파스텔 고급감 | 장식 과잉, 다크 UI, 노이즈 |
| 배경 | 소프트 블러, 세계의 깊이, 장소감, 파스텔 감정 온도 | 정보 과밀, 하드 엣지, 시선 분산 |

## 3. 플레이 관점 에센스

### 3-1. 전투 가독성

- 플레이어는 1초 안에 적의 역할과 위협도를 읽을 수 있어야 한다.
- 캐릭터는 감정 이입의 중심이므로 표정, 눈, 의상 색조가 먼저 읽혀야 한다.
- 몬스터는 공포보다 패턴 인지가 우선이다. 속성 시각 포인트가 즉시 인지되어야 한다.
- Tier 구분은 프레임 테두리 색으로만 — 몬스터 크기는 동일하다.

### 3-2. 카드 게임다움

- 모든 존재는 카드 형태로 표현된다 (세계관 일관성).
- 프레임은 세계관 장식이 아니라 정보 구조의 일부다.
- 양피지 재질이 카드의 물리적 존재감을 부여한다.
- 프레임 테두리 색으로 플레이어/일반/정예/보스가 한눈에 갈려야 한다.

### 3-3. 세계 일관성

- 캐릭터, 몬스터, 배경, UI는 서로 다른 화풍처럼 보이면 안 된다.
- 라벤더 기조 + 뮤트드 파스텔 + 양피지 재질 + 컬러 아웃라인이 통일감을 만든다.
- 이 일관성은 색, 외곽선 스타일, 셰이딩 기법, 재질감에서 나온다.

## 4. 시각 판단 체크포인트

| 판단 항목 | 질문 |
|-----------|------|
| 표정 | bust portrait의 표정만 보고 감정 축이 읽히는가? |
| 실루엣 | 축소해도 캐릭터와 몬스터의 정체가 읽히는가? |
| 색상 | 클래스(보석톤)/Tier(프레임)/속성(보석톤)의 구분이 섞이지 않는가? |
| 외곽선 | 컬러 라인이 파스텔 톤과 자연스럽게 어우러지는가? |
| 프레임 | 양피지 프레임이 카드 정보를 명확하게 전달하는가? |
| 배경 | 소프트 블러가 카드에 시선을 집중시키면서 분위기를 형성하는가? |
| 긴장감 | 채도/명도 시프트가 자연스럽게 아늑함→긴장→위기로 전환되는가? |

## 5. 우선순위 원칙

1. **가독성**이 장식보다 우선한다.
2. **세계 일관성**이 개별 에셋의 개성보다 우선한다.
3. **기획 정합성**이 멋있는 변형보다 우선한다.
4. **실행 프롬프트 정합성**이 설명 문구보다 우선한다.
5. **아늑함(Cozy)**이 기본이되, 긴장감은 색상으로만 조절한다.
