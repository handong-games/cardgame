# 몬스터 설계도 v6.0

> **최종 수정일**: 2026-03-16

## 목적

- 몬스터의 위협도, 속성 식별성, 지역별 톤, Tier 구분을 관리한다.

---

## 공통 규칙

| 항목 | 값 |
|------|-----|
| 렌더링 | 플랫 컬러 일러스트 (3~5색, 그라디언트/텍스처/셰이딩 없음) |
| 표현 방식 | **bust portrait** (가슴 중앙에서 크롭) |
| 구도 | 정중앙 배치, headroom 10~15%, 카드 면적의 85~90% 채움 |
| 등신 | 슈퍼 디포르메 치비 **2~2.5등신** |
| 방향 | 좌측 ← (대립, 위협, 3/4 각도) |
| 캔버스 | 2:3 세로형 (생성 512×768, 표시 240×360) |
| 멀티 몬스터 | 포커스+서브: 최고 Tier=풀사이즈, 저Tier=75%(180×270) 나란히 |
| 최대 동시 등장 | 2마리 (메인 1 + 서브 1) |
| Tier 구분 | **프레임 테두리 색상으로 구분** (T1=`#B8B8C8`, T2=`#C8B888`, T3=`#C89098`) |
| 외곽선 | 단일 색상 균일 굵기 아웃라인 (warm dark tone, 순수 검정 아님) |
| 얼굴 | **눈동자가 보이지 않는 작은 단순 눈**(tiny simplified eyes without visible pupils/irises), 최소 표현 |
| 색상 | 지역 파스텔 팔레트 종속 |
| 조명 | 따뜻한 자연광 (라벤더/쿨톤 색조 조명 금지) |
| 디자인 톤 | 위협적이지 않은 **귀여운 판타지 몬스터**, 실루엣 중심 디자인 |
| 배경 | 크림 양피지 `#F0E8D8` |
| 감정 | 공포 아닌 패턴 인지가 우선 |
| 색상 범위 | 뮤트드 따뜻한 파스텔 (채도 40~55%) |
| 프레임 | CSS 프로그래매틱 — Tier색 3~5px 보더 + 양피지 리본 네임플레이트 |

> **카드 UI 레이아웃 상세**: `docs/설계도/카드-UI-레이아웃-v6.md` 참조

## 관리 포인트

|------|------|
| 방향 | 좌측 ← |
