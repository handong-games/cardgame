# 배경 설계도 v6.0

> **최종 수정일**: 2026-03-16

## 목적

- 전투/비전투 배경의 장소감, 분위기, 채도 시프트 긴장 연출을 관리한다.

---

## 공통 규칙

| 항목 | 값 |
|------|-----|
| 기법 | **소프트 일러스트** (부드러운 수채화풍) |
| 블러 | 60~70% 블러 처리 (카드에 시선 집중) |
| 내용 | **환경만** (나무, 동굴, 성벽 등 풍경) |
| 금지 | 캐릭터, 몬스터, 생물 배치 금지 |
| 해상도 | 1920×1080 (16:9) |
| 색조 | 라벤더 기조 + 지역별 보조색 |
| 중앙 | 카드/UI 공간을 위해 개방 유지 |
| 색상 범위 | 뮤트드 파스텔 (채도 40~55%) |

> v5의 2-Tier 시스템(실루엣+스토리북)을 폐기하고, 단일 소프트 일러스트 시스템으로 통합.

---

## 지역별 배경

| 지역 | 환경 요소 | 색조 | 분위기 |
|------|----------|------|--------|
| 잊혀진 숲 | 나무 실루엣, 빛줄기, 안개, 이끼 | 민트+라벤더 (`#C8D8C8` ~ `#D0C8E0`) | 신비로운 숲 |
| 던전 | 동굴 벽, 수정, 희미한 빛 | 스카이+라벤더 (`#C0C8D8` ~ `#C8C0D8`) | 차가운 미스터리 |
| 성 | 성벽, 커튼, 스테인드글라스 | 로즈+라벤더 (`#D8C0C8` ~ `#D0C0D8`) | 위엄 있는 긴장 |

---

## 잊혀진 숲 배경 상세

| 항목 | 값 |
|------|-----|
| 장면 | 숲 속 — 나무 실루엣, 안개, 빛줄기 |
| 색조 | 민트+라벤더 파스텔 |
| 상단 | 나뭇가지 캐노피 (빛 유입) |
| 좌우 | 고목 실루엣 + 이끼/덩굴 |
| 중앙 | 개방 (카드/UI 공간) |
| 바닥 | 낙엽 + 이끼 (소프트 블러) |
| 분위기 | 아늑하고 신비로운 숲, 몽환적 |

---

## 긴장감 채도 시프트 (3단계)

| 단계 | 적용 라운드 | 시각적 변화 | 톤 |
|------|-----------|-----------|-----|
| 평온 | R1~3 | 순수 파스텔 그대로 | 밝고 아늑한 라벤더 |
| 긴장 | R4~5 | 채도 +15%, 명도 -10% | 약간 진해진 라벤더 |
| 위기 | R6~8+보스 | 채도 +30%, 명도 -20% | 딥 퍼플/딥 로즈 톤 |

> 구현: 기본 1장 생성 후, 게임 엔진에서 색상 필터/오버레이로 채도 시프트 처리.

## QA 질문

- 소프트 블러가 카드에 시선을 집중시키면서 분위기를 형성하는가?
- 장소의 감정 온도가 분명한가?
- 캐릭터/몬스터 없이 환경만으로 세계관이 전달되는가?
- 3단계 채도 시프트가 자연스러운가?
- 중앙 개방 영역이 충분한가?
- 지역별 파스텔 색조가 구분되면서 라벤더 통일감을 유지하는가?
