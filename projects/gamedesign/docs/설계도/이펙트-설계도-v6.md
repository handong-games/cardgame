# 이펙트 설계도 v6.0

> **최종 수정일**: 2026-03-16

## 목적

- 전투 이펙트의 색 언어와 정보 위계를 관리한다.

---

## 현재 상태

> 이펙트 에셋은 **게임 구현 단계**에서 제작한다. 이 문서는 제작 시 참조할 기준만 기록한다.

---

## 핵심 규칙

- 이펙트는 화려함보다 **판정 전달**이 우선이다.
- 기본 이펙트는 골드/스카이/세이지, 속성 이펙트는 보석톤 6색 고정.
- 지역이 바뀌어도 속성 인지는 흔들리면 안 된다.
- 발광은 파스텔 세계관 안에서 읽히는 범위로 절제한다.
- 채도 40~55% 범위 유지.

---

## 색 언어 기준

### 기본 이펙트 (3종)

| 유형 | 이름 | HEX | 시각적 표현 |
|------|------|-----|-----------|
| 공격 | 골드 | `#C9A86C` | 골드빛 섬광 |
| 방어 | 스카이 | `#A0B8D4` | 파란 쉴드 발광 |
| 회복 | 세이지 | `#A0C8A0` | 녹색 파티클 상승 |

### 속성 이펙트 (6종)

| 속성 | 이름 | HEX | 시각적 표현 |
|------|------|-----|-----------|
| 독 (Poison) | 뮤트드 에메랄드 | `#7AB88A` | 녹색 연기/방울 |
| 포자 (Spore) | 뮤트드 아메시스트 | `#9A80B8` | 보라 포자 부유 |
| 가시 (Thorns) | 뮤트드 로즈 | `#C07878` | 핑크 가시 반사 |
| 경화 (Hardening) | 뮤트드 실버 | `#9898A8` | 은빛 경화 표면 |
| 회피 (Evasion) | 뮤트드 스카이 | `#78A8C0` | 잔상/투명화 |
| 취약 (Vulnerable) | 뮤트드 와인 | `#B868A0` | 보라빛 균열 |

## 제작 가이드라인 (게임 구현 시 참조)

| 항목 | 기준 |
|------|------|
| 형태 | 스프라이트 시트 또는 파티클 |
| 밀도 | 짧고 명확한 파티클 중심 |
| 채도 | 뮤트드 파스텔 40~55% (다른 에셋과 통일) |
| 우선순위 | 결과 전달 > 감정 연출 |
| 개수 | 기본 3종 + 속성 6종 = 9종 |
| 발광 강도 | 파스텔 세계관 내 절제된 발광 |
