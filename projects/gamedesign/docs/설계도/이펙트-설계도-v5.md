# 이펙트 설계도 v5.0

> **최종 수정일**: 2026-03-15

## 목적

- 전투 이펙트의 색 언어와 정보 위계를 관리한다.

---

## 현재 상태

> 이펙트 에셋은 **게임 구현 단계**에서 제작한다. 이 문서는 제작 시 참조할 기준만 기록한다.

---

## 핵심 규칙

- 이펙트는 화려함보다 판정 전달이 우선이다.
- 기본 이펙트는 앰버, 속성 이펙트는 고정 색 언어를 유지한다.
- 리전이 바뀌어도 속성 인지는 흔들리면 안 된다.
- 발광은 어두운 세계 안에서 읽히는 범위로 절제한다.

---

## 색 언어 기준

### 기본 이펙트

| 유형 | 색상 | HEX |
|------|------|-----|
| 공격 | 앰버/골드 | `#D4A574` |
| 방어 | 앰버/골드 | `#D4A574` |
| 회복 | 앰버/골드 | `#D4A574` |

### 속성 이펙트 (속성당 1개 대표)

| 속성 | 색상 | HEX 기준 | 시각적 표현 |
|------|------|---------|-----------|
| 독 (Poison) | 녹색 | `#4A6741` | 독액 방울/연기 |
| 포자 (Spore) | 보라 | `#6B4B8C` | 포자 구름 |
| 가시 (Thorns) | 적색 | `#8B4049` | 가시 튕김 |
| 경화 (Hardening) | 회색 | `#5A5F6B` | 돌 코팅 |
| 회피 (Evasion) | 하늘색 | `#5B9EA0` | 잔상/페이드 |
| 취약 (Vulnerable) | 자주색 | `#7B5BA0` | 균열 빛남 |

## 제작 가이드라인 (게임 구현 시 참조)

| 항목 | 기준 |
|------|------|
| 형태 | 스프라이트 시트 또는 파티클 |
| 밀도 | 짧고 명확한 파티클 중심 |
| 우선순위 | 결과 전달 > 감정 연출 |
| 개수 | 기본 3종 + 속성 6종 = 9종 |
| 채도 | 뮤트드 40~55% (다른 에셋과 통일) |

## 관리 포인트

| 항목 | 기준 |
|------|------|
| 기본 공격/방어/회복 | 앰버/골드 발광 |
| 속성 | 독=녹, 포자=보라, 가시=적, 경화=회색, 회피=하늘색, 취약=자주 |
| 표현 밀도 | 짧고 명확한 파티클 중심 |
| 우선순위 | 결과 전달 > 감정 연출 |
| 원칙 문서 | `docs/비주얼-디자인-DNA-v5.md` §7 |
