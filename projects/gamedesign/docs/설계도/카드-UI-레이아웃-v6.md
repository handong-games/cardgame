# 카드 UI 레이아웃 v6.0

> **최종 수정일**: 2026-03-16
> **적용 대상**: 캐릭터 카드, 몬스터 카드 (스킬 카드·동료 카드는 별도)

---

## 1. 개요

전투 화면에서 캐릭터와 몬스터는 **카드 대치형**으로 표시된다.
좌측에 플레이어 카드, 우측에 몬스터 카드를 세워 대치하는 구조.
카드 자체가 전장의 유닛이며, "모든 개체가 카드 안에 존재하는 세계관"을 시각적으로 구현한다.

---

## 2. 카드 치수

| 항목 | 값 | 비고 |
|------|-----|------|
| 생성 해상도 | **512×768px** | AI 이미지 생성 규격 |
| 표시 크기 | **240×360px** | 게임 화면(1920×1080) 기준 |
| 화면 비율 | 33% (높이 기준) | |
| 종횡비 | **2:3 세로형** | |
| 모서리 | **10px radius** (소프트 라운드) | |

## 3. 카드 구조 다이어그램

```
  ╔═══════════════════════════════╗ ←── 프레임: 3~5px 컬러 보더
  ║                               ║     (CSS 프로그래매틱 렌더링)
  ║       ~10~15% headroom        ║
  ║          ┌─────────┐          ║
  ║          │    ○    │          ║
  ║          │   ╱│╲   │          ║
  ║          │    █    │  bust    ║ ←── 초상화 영역: 풀 블리드 85~90%
  ║          │    █    │ portrait ║     정중앙 배치, 3/4 각도
  ║          │    █    │          ║     크림 양피지 배경 #F0E8D8
  ║ ─ ─ ─ ─ │────█────│ ─ ─ ─ ─ ║ ←── crop line: 가슴 중앙
  ║                               ║
  ║  ╔═══════════════════════════╗║
  ║  ║     ╠══ 이름 ══╣         ║║ ←── 양피지 리본 네임플레이트
  ║  ╚═══════════════════════════╝║     13~15% 높이
  ╚═══════════════════════════════╝
  ░░░░░░ soft drop shadow ░░░░░░░░
```

## 4. 카드 내부 요소

### 4-1. 초상화 영역

| 항목 | 값 |
|------|-----|
| 비율 | 카드 면적의 **85~90%** (풀 블리드) |
| 크롭 포인트 | **가슴 중앙** (얼굴 + 어깨 + 의상 상부 노출) |
| 머리 위 여백 (headroom) | 카드 높이의 **10~15%** (36~54px 표시 기준) |
| 수평 위치 | **정중앙** |
| 배경색 | 크림 양피지 `#F0E8D8` |
| 방향 | 캐릭터: 우측 → (3/4 각도) / 몬스터: 좌측 ← (3/4 각도) |

### 4-2. 양피지 리본 네임플레이트

카드 위 유일한 ON-card UI 요소.

| 항목 | 값 |
|------|-----|
| 형태 | **양끝 접힘형 리본 배너** |
| 위치 | 카드 하단 |
| 높이 | 카드 높이의 **13~15%** (47~54px 표시 기준) |
| 배경 | 양피지 크림 `#F0E8D8` |
| 텍스트 색 | 다크 라벤더 `#3A3040` |
| 내용 | 이름만 (예: "전사", "고블린") |
| 결합감 | 프레임 하단에 자연스럽게 붙은 종이 배너처럼 보일 것 |

#### 캐릭터/몬스터 네임플레이트 규격

| 구분 | 규격 | 비고 |
|------|------|------|
| 메인 카드 네임플레이트 | **200×44px** | 플레이어/메인 몬스터 공통 |
| 서브 몬스터 네임플레이트 | **142×36px** | 170×255 서브 카드 전용 축소형 |
| 리본 날개 폭 | 좌우 **18~22px** | 양끝 접힘형 리본 |
| 테두리 | `1px solid #d8cdb8` | 양피지 패널 외곽선 |
| 내부 패딩 | 좌우 16~20px | 이름 1줄 기준 |

### 4-3. 프레임

| 항목 | 값 |
|------|-----|
| 렌더링 방식 | **프로그래매틱 (CSS/코드)** — AI 생성이 아님 |
| 두께 | **3~5px** (표시 기준) |
| 모서리 | **10px radius** |
| 색상 | 아래 색상 체계 참조 |
| 그림자 | soft drop shadow `rgba(58,48,64,0.3)` blur 8px offset-y 4px |

#### 프레임 외곽선 규격

| 구분 | 규격 | 비고 |
|------|------|------|
| 메인 카드 외곽선 | **3~5px** | 캐릭터/메인 몬스터 공통 |
| 서브 몬스터 외곽선 | **3px** | 메인보다 가볍게 유지 |
| 코너 라운드 | **10px** | 메인/서브 공통 |
| 외곽선 색상 | 클래스/Tier 색상 | 캐릭터=클래스, 몬스터=Tier |
| 내부 인셋 여백 | **12px** | 초상화 배경과 프레임 분리 |

#### 카드 내부 캐릭터/몬스터 규격

| 구분 | 내부 일러스트 규격 | 비고 |
|------|------------------|------|
| 플레이어 메인 카드 | **약 96×122px** | 우측 3/4 각도, 중앙 정렬 |
| 몬스터 메인 카드 | **약 92×118px** | 좌측 3/4 각도, 중앙 정렬 |
| 서브 몬스터 카드 | **약 72×90px** | 메인 대비 축소, 하단 정렬 카드에 맞춤 |
| 메인 카드 내부 초상화 창 | **약 216×288px** | 240×360 카드에서 12px 인셋 기준 |
| 서브 카드 내부 초상화 창 | **약 150×194px** | 170×255 카드에서 10px 인셋 기준 |
| 공통 headroom | 카드 높이의 **10~15%** | 머리 위 여백 |
| 공통 크롭 | **mid-chest upward** | 가슴 중앙 기준 bust portrait |

#### 프레임 색상 체계

**캐릭터 (보석톤 클래스색)**:

| 클래스 | 프레임 HEX | 이름 |
|--------|-----------|------|
| 전사 | `#E8B4B8` | 로즈쿼츠 |
| 마법사 | `#B8A0D0` | 아메시스트 |
| 도적 | `#A0C8B0` | 에메랄드 |

**몬스터 (Tier × 지역색)**:

| Tier | 프레임 HEX | 이름 |
|------|-----------|------|

| T2 정예 | `#C8B888` | 뮤트드 골드 |
| T3 보스 | `#C89098` | 뮤트드 로즈 |

## 5. 카드 외부 UI 요소

카드 위가 아닌 카드 **주변**에 배치되는 요소.

### 5-1. 상단 — HP / 방어도 / 인텐트

| 항목 | 형태 | 위치 |
|------|------|------|
| HP | `♥` 아이콘 + 숫자 (예: `♥ 70`) | 카드 상단 좌측 |
| 방어도 | `🛡` 아이콘 + 숫자 (예: `🛡 5`) | HP 우측 |
| 인텐트 (몬스터 전용) | 행동 아이콘 + 수치 (예: `⚔ 6`) | 카드 상단 좌측 |

```
  캐릭터:  ♥ 70  🛡 5          몬스터:  ⚔ 6  ♥ 18
          ╔══════════╗                ╔══════════╗
```

### 5-2. 하단 — 상태이상 아이콘

| 항목 | 형태 | 위치 |
|------|------|------|
| 상태이상 | 속성 아이콘 뱃지 + 스택 수 | 카드 하단 외부 |

```
          ╚══════════╝
          ◇ 독2  ◇ 포자1
```

### 5-3. 호버 — 상세 정보 사이드 툴팁

| 항목 | 값 |
|------|-----|
| 트리거 | 카드 호버 시 |
| 위치 | 캐릭터 카드 → 우측 / 몬스터 카드 → 좌측 |
| 내용 | 클래스명, 속성 태그, 스킬 목록, 약점 등 |
| 스타일 | 양피지 톤 패널 (`#F0E8D8` 배경) |

## 6. 멀티 몬스터 레이아웃

몬스터가 여러 마리일 때의 카드 배치. **포커스(메인) + 서브(나란히)** 방식.

| 항목 | 값 |
|------|-----|
| 방식 | 최고 Tier = 풀사이즈 메인 / 저Tier = 축소 서브 |
| 메인 카드 | **240×360px** (표시 기준) |
| 서브 카드 | **180×270px** (메인의 75%) |
| 최대 동시 등장 | **2마리** (메인 1 + 서브 1) |
| 서브 위치 | 메인 카드 옆에 나란히 |

```
  1마리:            2마리 (메인 + 서브):
  ╔══════════╗      ╔══════════╗ ╔═══════╗
  ║          ║      ║          ║ ║       ║
  ║   메인   ║      ║   메인   ║ ║  서브  ║
  ║ 240×360  ║      ║ 240×360  ║ ║180×270║
  ║          ║      ║          ║ ║       ║
  ╚══════════╝      ╚══════════╝ ╚═══════╝
```

## 7. 카드 상태

| 상태 | 표현 | 시간 |
|------|------|------|
| **기본** | 정위치 | — |
| **선택/활성** | 위로 8px 상승 | 150ms ease-out |
| **피격** | 좌우 흔들림 + 빨간 플래시 | 200ms |
| **사망** | 회색화(desaturate) + 30° 기울어지며 페이드아웃 | 500ms |

## 9. AI 이미지 생성 프롬프트 규격

프레임은 CSS로 렌더링하므로, AI는 **순수 초상화**만 생성한다.

### 9-1. 프롬프트에 반영할 카드 레이아웃 키워드

| 레이아웃 결정 | 프롬프트 키워드 |
|-------------|---------------|
| 크롭: 가슴 중앙 | `bust portrait from mid-chest upward` |
| headroom 10~15% | `moderate headroom above the head` |
| 수평 정중앙 | `centered composition` |
| 풀블리드 85~90% | `character fills most of the frame` |
| 크림 양피지 배경 | `solid cream parchment background #F0E8D8` |
| 프레임 없음 | `no border no frame` |
| 비율 2:3 | `vertical portrait 2:3 aspect ratio` |

### 9-2. 캐릭터/몬스터 공통 렌더 베이스 키워드

```
simple flat color illustration with clean solid fills and no gradients,
bust portrait from mid-chest upward,
centered composition with moderate headroom above the head,
character fills most of the frame,
super-deformed chibi proportions around 2 to 2.5 head body ratio,
flat coloring with only 3 to 5 colors per character and no shading or tonal layering,
single color uniform weight outline in warm dark tone,
muted warm pastel colors strictly 40 to 55 percent saturation,
silhouette-driven character design recognizable from shape alone,
small simple dot eyes with short simple line eyebrows and minimal facial features with no nose detail,
solid cream parchment background #F0E8D8,
no border no frame,
vertical portrait 2:3 aspect ratio
```

### 9-3. 금지 키워드 (NEGATIVE)

```
realistic, photorealistic, 3D render, CGI,
anime manga style,
tonal layering, soft shading, gradient shading, cel-shading,
visible brushwork, brush strokes, paint texture, paper grain, gouache texture,
detailed eyes with highlights and reflections, large expressive eyes,
complex accessories, ornate decoration, intricate patterns,
clean smooth airbrushed digital rendering, polished vector art,
lavender tint, purple ambient light, cool color cast,
complex detailed background, white background,
full body, legs, feet,
blurry low quality
```

## 10. 관리 포인트

| 항목 | 기준 |
|------|------|
| 표시 크기 변경 시 | 생성 해상도(512×768)는 유지, 표시 크기만 조정 |
