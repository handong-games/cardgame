# 캐릭터 설계도 v6.0

> **최종 수정일**: 2026-03-16

## 목적

- 플레이어 클래스, 동료, NPC의 감정 이입 중심 축을 관리한다.

---

## 공통 규칙

| 항목 | 값 |
|------|-----|
| 렌더링 | 플랫 컬러 일러스트 (3~5색, 그라디언트/텍스처/셰이딩 없음) |
| 표현 방식 | **bust portrait** (가슴 중앙에서 크롭) |
| 구도 | 정중앙 배치, headroom 10~15%, 카드 면적의 85~90% 채움 |
| 등신 | 슈퍼 디포르메 치비 **2~2.5등신** |
| 연령 | 불특정 — "귀엽고 용감한 모험가" |
| 방향 | 우측 → (3/4 각도, looking toward right side) |
| 캔버스 | 2:3 세로형 (생성 512×768, 표시 240×360) |
| 외곽선 | 단일 색상 균일 굵기 아웃라인 (warm dark tone, 순수 검정 아님) |
| 배경 | 크림 양피지 `#F0E8D8` |
| 얼굴 | **눈동자가 보이지 않는 작은 단순 눈** + 간단한 선 눈썹(short simple line eyebrows), 코 생략, 최소 표현 |
| 헤어 | 클래스별 개성 있는 실루엣 헤어 — 실루엣만으로 클래스 식별 가능해야 함 |
| 감정 | 용기, 결의, 친근함, 모험심 |
| 디자인 원칙 | **실루엣이 캐릭터를 정의** — 소품 1~2개 최대, 장식 최소화 |
| 조명 | 따뜻한 자연광 (라벤더/쿨톤 색조 조명 금지) |
| 색상 범위 | 뮤트드 따뜻한 파스텔 (채도 40~55%) |
| 금지 색상 | 순수 검정/흰색, 네온/비비드, 채도 60% 이상 |
| 프레임 | CSS 프로그래매틱 — 보석톤 클래스색 3~5px 보더 + 양피지 리본 네임플레이트 |

> **카드 UI 레이아웃 상세**: `docs/설계도/카드-UI-레이아웃-v6.md` 참조
