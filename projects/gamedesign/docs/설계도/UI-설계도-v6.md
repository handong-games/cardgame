# UI 설계도 v6.0

> **최종 수정일**: 2026-03-16

## 목적

- 코인, 버튼, HP바, 상태이상 아이콘 등 UI 요소의 기능 우선 디자인을 관리한다.

---

## 공통 규칙

| 항목 | 값 |
|------|-----|
| 철학 | 기능 우선, 노이즈 최소화 |
| 색상 | 뮤트드 파스텔 팔레트 + 골드(`#C9A86C`) 악센트 |
| 재질 | 양피지/크림(`#F0E8D8`) (카드 프레임과 통일) |
| 폰트 | 둥근 산세리프 |
| 텍스트 주요 | 다크 라벤더 `#3A3040` |
| 텍스트 보조 | 뮤트드 그레이 `#6A6070` |
| 색상 범위 | 뮤트드 파스텔 (채도 40~55%) |

## 코인 — 해/달 보석 코인

| 항목 | 앞면 (Heads) | 뒷면 (Tails) |
|------|-------------|-------------|
| 형태 | **해 문양 보석 코인** (반투명 보석 재질) | **달 문양 보석 코인** (반투명 보석 재질) |
| 심볼 | 중앙 해 문양 + 짧은 광선 | 중앙 초승달 + 작은 별 2개 |
| 색상 | 선 골드 `#C9A86C` + 웜 크림 하이라이트 | 문 퍼플 `#6A5080` + 라벤더 크림 하이라이트 |
| 연상 | 희망, 직진성, 밝은 결과 | 신비, 변수, 차분한 다른 결과 |
| 생성 해상도 | 256×256 px | 256×256 px |
| 비율 | 1:1 원형 | 1:1 원형 |
| 배경 | 순백 추출용 | 순백 추출용 |
| 플립 효과 | 보석이 회전하며 빛이 반사되는 애니메이션 |

### 코인 주머니

| 항목 | 값 |
|------|-----|
| 형태 | 작은 **양피지-가죽 혼합 질감** 드로우스트링 주머니 |
| 기본 색상 | 웜 크림 + 뮤트드 골드 `#C8B888` |
| 보조 색상 | 라벤더 안감 + 해/달 비즈 포인트 |
| 내용물 | 코인 없이 비어 있는 상태로 생성 |
| 인상 | 코인과 같은 세계관의 아늑한 모험 장비, 장식 과다 금지 |
| 배경 | 순백 추출용 |

## HP & 방어도

| 항목 | 값 |
|------|-----|
| HP 표시 | **바(Bar) 형태** |
| HP 위치 | **카드 프레임 상단 외곽** |
| HP 색상 | 로즈 → 회색 감소 (`#E8B4B8` → `#A0A0A8`) |
| 방어도 | HP바 위에 **파란 오버레이** (`#A0B8D4`) |

## 상태이상 아이콘 (6종)

| 속성 | 이름 | HEX | 형태 |
|------|------|-----|------|
| 독 | 뮤트드 에메랄드 | `#7AB88A` | 독방울 아이콘 |
| 포자 | 뮤트드 아메시스트 | `#9A80B8` | 포자 구름 아이콘 |
| 가시 | 뮤트드 로즈 | `#C07878` | 가시 아이콘 |
| 경화 | 뮤트드 실버 | `#9898A8` | 방패/돌 아이콘 |
| 회피 | 뮤트드 스카이 | `#78A8C0` | 바람/잔상 아이콘 |
| 취약 | 뮤트드 와인 | `#B868A0` | 균열 아이콘 |

**배치 규칙:**
- 위치: 카드 프레임 하단 외곽
- 형태: 작은 원형 아이콘 + 스택 숫자
- 배열: 좌→우 일렬
