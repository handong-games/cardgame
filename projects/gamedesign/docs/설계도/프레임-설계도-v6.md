# 프레임 설계도 v6.0

> **최종 수정일**: 2026-03-16

## 목적

- 카드와 UI 프레임의 정보 위계, 재질감, 색상 코드 관리를 담당한다.

### ⚠️ 프레임 구현 방식 이원화 (v6.0 카드 UI 레이아웃 반영)

| 프레임 유형 | 구현 방식 | 비고 |
|------------|----------|------|
| **캐릭터/몬스터 카드** | **CSS 프로그래매틱** | AI로 프레임 이미지 생성하지 않음. 코드로 렌더링. `카드-UI-레이아웃-v6.md` 참조 |
| **스킬 카드** | **AI 이미지 생성** | 기존대로 프롬프트로 프레임 이미지 생성 |
| **동료 카드** | **CSS 프로그래매틱** | 원형 프레임을 코드로 렌더링 |

> 캐릭터/몬스터 프레임 프롬프트(`frame-player`, `frame-t1~t3`, `frame-companion`)는 **디자인 참조용**으로만 유지한다. 실제 게임에서는 CSS로 구현된다.

## 카드 정보 레이아웃 (캐릭터/몬스터 카드)

> 상세 스펙은 `docs/설계도/카드-UI-레이아웃-v6.md` 참조

```
       HP바 · 방어도 · 인텐트         ← 카드 상단 외곽 (off-card)
  ╔═══════════════════════════════╗ ←── 프레임: 3~5px 컬러 보더 (CSS)
  ║       ~10~15% headroom        ║
  ║          ┌─────────┐          ║
  ║          │    ○    │          ║
  ║          │   ╱│╲   │  bust    ║ ←── 초상화: 풀 블리드 85~90%
  ║          │    █    │ portrait ║     정중앙, 크림 양피지 배경
  ║          │    █    │          ║
  ║ ─ ─ ─ ─ │────█────│ ─ ─ ─ ─ ║ ←── crop: 가슴 중앙
  ║  ╔═══════════════════════════╗║
  ║  ║     ╠══ 이름 ══╣         ║║ ←── 양피지 리본 (13~15%)
  ║  ╚═══════════════════════════╝║
  ╚═══════════════════════════════╝
  ░░░░░░ soft drop shadow ░░░░░░░░
       [🍀2] [💀3]                   ← 상태 아이콘: 카드 하단 외곽
```

**핵심 원칙:**
- 프레임은 **CSS 프로그래매틱** — AI가 프레임을 생성하지 않음
- HP/방어도/인텐트는 카드 **상단 외곽**, 상태이상은 카드 **하단 외곽** → 일러스트 면적 최대화
- 카드 내부(ON-card)는 **bust portrait + 양피지 리본 네임플레이트**에만 집중
- 프레임 내부는 **자연스럽게 비어 있어야 하며**, 추가 상자/패널/플레이트가 생기면 안 됨
- 이름은 양끝 접힘형 양피지 리본에 다크 라벤더 `#3A3040`
- 클래스/속성 등 상세 정보는 **호버 시 사이드 툴팁**으로 표시
- 캐릭터/몬스터 프레임 참조 이미지는 **분홍 띠가 전체 카드 비율을 정확히 따라가야 하며**, 네임플레이트는 프레임 위에 겹쳐 얹힌 느낌으로 본다
- 캐릭터/몬스터 프레임의 **하단 외곽 폭도 좌우와 동일**해야 하며, 네임플레이트는 약간 위로 올라가 분홍 띠가 리본 중단 뒤로 살짝 보이게 배치한다
- 위 캐릭터/몬스터 프레임 기준은 **플레이어, T1, T2, T3 프레임 전체에 동일하게 적용**한다

### 네임플레이트 결합 원칙

| 항목 | 기준 |
|------|------|
| 결합 방식 | 프레임 하단과 **한 몸처럼 연결**되어 떠 보이지 않아야 함 |
| 형태 | 양끝 접힘형 리본 + 중앙 직사각 패널 |
| 높이 | 카드 높이의 **13~15%** |
| 세로 위치 | 카드 하단에 더 가깝게 두되, 리본 중단 뒤로 분홍 띠가 소량 보이게 |
| 좌우 여백 | 프레임 안쪽에서 균형 있게 inset 유지 |
| 깊이감 | 미세한 종이 겹침/내측 그림자로만 표현, 과한 장식 금지 |
| 금지 | 공중에 뜬 배너, 금속 명판, 과도한 입체감, 화려한 문양 |

## 스킬 카드 레이아웃

```
┌────────────┐
│            │
│  ┌──────┐  │
│  │      │  │         ← 단일 내부 정사각 프레임만 생성
│  │  icon│  │            외곽은 조용한 여백으로 유지
│  │      │  │
│  └──────┘  │
│            │
└────────────┘
```

- 스킬 프레임 AI 이미지는 **큰 바깥 프레임 안에 추가 장식이 들어가면 안 됨**
- 중앙의 **단일 작은 정사각 프레임 형태만** 읽히도록 유지
- 중앙 프레임 안의 **흰색 독립 사각형 패널은 금지**하고, 동일한 양피지 재질 계열로 유지
- 스킬 프레임 안쪽도 **자연스럽게 빈 상태**로 두고, 추가 상자나 플레이트를 넣지 않음
- 위 스킬 프레임 기준은 **공격/방어/버프/유틸 4종 전체에 동일하게 적용**한다

## 구분 원칙

- **캐릭터 vs 몬스터**: 클래스별 보석톤 테두리(CSS) vs Tier별 실버/골드/로즈 테두리(CSS)
- **스킬 4종**: 테두리 색 + 상단 타입 아이콘으로 구분 (AI 이미지 생성)
- **스킬 카드 비율**: 배틀씬/상점 UI 스펙에 맞춰 1:1 정사각 생성 후 140×140 슬롯에 사용
- **몬스터 Tier**: 실버→골드→로즈 프레임 색으로만 구분 (크기 동일)
- **동료**: 원형 프레임(CSS)으로 형태 자체가 구분
