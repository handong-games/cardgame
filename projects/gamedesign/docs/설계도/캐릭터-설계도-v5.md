# 캐릭터 설계도 v5.0

> **최종 수정일**: 2026-03-15

## 목적

- 플레이어 클래스와 동료의 감정 이입 중심 축을 관리한다.

---

## 공통 규칙

| 항목 | 값 |
|------|-----|
| 렌더링 | 전신 스토리북 렌더링 |
| 나이대 | 13~15세 소년 |
| 등신 | 2.5~3등신 (모든 클래스 동일) |
| 체형 차이 | 전사=다부진, 마법사=왜소한, 도적=날렵한 |
| 방향 | 우측 대각선 ↗ |
| 캔버스 | 2:3 세로형 (1024×1536 생성, 게임 내 축소) |
| 게임 해상도 | 1080p (1920×1080) |
| 명암 | 상체(얼굴·장비) 디테일 집중 + 하체 완만한 감쇠 |
| 외곽선 | 얇은 니어블랙 `#1A1A1E` |
| 텍스처 | 종이 질감 5~8% |
| 배경 | 순백 `#FFFFFF` 추출용 |
| 읽기 순서 | 얼굴 → 눈 → 주무기 → 상체 장비 |
| 감정 | 희망, 결의, 인간적 온기, 소년미 |

---

## 클래스별 스펙

### 전사 (CLS_W) — 확정

| 항목 | 값 |
|------|-----|
| 고유색 | 앰버/골드 `#D4A574` |
| 머리색 | 따뜻한 갈색, 짧고 헝클어진 |
| 체형 | 다부진 (넓은 어깨, 탄탄한 체격) |
| 주무기 | 한손검 |
| 의상 | 가죽+금속 혼합 갑옷, 허리 벨트, 짧은 망토 |
| 표정 | 희망에 찬 밝은 미소, 반짝이는 눈 |
| 포즈 | 검을 한 손에 들고 결의에 찬 자세 |
| designStatus | `confirmed` |
| 프롬프트 | `src/data/promptExamples.ts` → character → warrior |

### 마법사 (CLS_M) — 비주얼 컨셉

| 항목 | 값 |
|------|-----|
| 고유색 | 뮤트드 틸 `#5B9EA0` |
| 머리색 | 다크 블루그린, 단정하고 긴 앞머리 |
| 체형 | 왜소한 (가늘고 작은 체격) |
| 주무기 | 나무 지팡이 |
| 보조 | 허리에 매단 책 |
| 의상 | 틸 톤 로브 |
| 표정 | 호기심, 지적 탐구, 소년미 |
| 포즈 | 지팡이 한 손 + 다른 손에 빛나는 오브/마법진 |
| designStatus | `undesigned` (gameplan 미확정) |
| 프롬프트 | gameplan 확정 후 작성 |

### 도적 (CLS_R) — 비주얼 컨셉

| 항목 | 값 |
|------|-----|
| 고유색 | 뮤트드 크림슨 `#8B4049` |
| 머리색 | 다크 적갈색, 거칠고 들쭉날쭉 |
| 체형 | 날렵한 (가늘고 민첩한 체격) |
| 주무기 | 쌍검 |
| 의상 | 다크 가죽 갑옷, 후드 달린 짧은 망토 |
| 표정 | 대담함, 장난기, 소년미 |
| 포즈 | 쌍검 교차, 살짝 웅크린 전투 자세 |
| designStatus | `undesigned` (gameplan 미확정) |
| 프롬프트 | gameplan 확정 후 작성 |
