# 프레임 설계도 v5.0

> **최종 수정일**: 2026-03-15

## 목적

- 카드와 UI 프레임의 정보 위계와 기능적 안정감을 관리한다.

---

## 공통 규칙

| 항목 | 값 |
|------|-----|
| 장식 | 미니멀 (깔끔한 직선 + 글로우만, 장식 요소 없음) |
| 악센트 | 테두리에 글로우/발광 |
| 외곽 밖 | 순백 `#FFFFFF` 추출용 |

| 게임 해상도 | 1080p (1920×1080) |

## 구분 원칙

- **캐릭터 vs 몬스터**: 글로우 색(앰버 vs 실버/퍼플/크림슨)으로 즉시 구분
- **스킬 4종**: 색상으로 구분 (빨강=공격, 파랑=방어, 초록=버프, 보라=유틸)
- **몬스터 Tier**: 실버→퍼플→크림슨 + 프레임 무게감 증가
- **동료**: 원형 프레임으로 형태 자체가 구분
