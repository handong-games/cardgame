# UI 설계도 v5.0

> **최종 수정일**: 2026-03-15

## 목적

- 버튼, 코인, 아이콘의 기능 우선 디자인을 관리한다.

---

## 공통 규칙

| 항목 | 값 |
|------|-----|
| 철학 | 기능 우선, 노이즈 최소화 |
| 색상 | 유니버설 다크 팔레트 + 앰버(`#D4A574`) 악센트 |
| 배경 | 어두운 전투 배경 위 가독성 확보 |
| 게임 해상도 | 1080p (1920×1080) |
| 모바일 | 미고려 |
| 재질감 | 카드 프레임/배경과 통일된 종이+금속 질감 |

---

## 우선 제작 에셋 (Phase 1)

### 1. 코인 — 해와 달

| 항목 | 앞면 (Heads) | 뒷면 (Tails) |
|------|-------------|-------------|
| 문양 | 태양 | 초승달 |
| 재질 | 금속 (금화) | 금속 (금화) |
| 생성 해상도 | 256×256 px | 256×256 px |
| 비율 | 1:1 원형 | 1:1 원형 |
| 색상 톤 | 앰버/골드 `#D4A574` | 실버/블루그레이 |
| 배경 | 순백 추출용 | 순백 추출용 |

### 2. 방어도 아이콘

| 항목 | 값 |
|------|-----|
| 형태 | 강철 방패 |
| 생성 해상도 | 128×128 px |
| 비율 | 1:1 |
| 색상 | 다크 팔레트 (`#2A2A32` base, `#4A4A55` 하이라이트) |
| 악센트 | 앰버 `#D4A574` 미세 테두리 발광 |

### 3. 턴 종료 버튼

| 항목 | 값 |
|------|-----|
| 형태 | 가로 직사각형, 모서리 둥글게 |
| 아이콘 | 모래시계 |
| 생성 해상도 | 320×96 px |
| 비율 | 약 3.3:1 |
| 색상 | 다크 팔레트 base + 앰버 악센트 |
| 상태 | 활성=앰버 글로우 발광, 비활성=어둡게 |
