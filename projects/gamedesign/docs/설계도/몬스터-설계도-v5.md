# 몬스터 설계도 v5.0

> **최종 수정일**: 2026-03-15

## 목적

- 몬스터의 위협도, 속성 식별성, 지역별 톤을 관리한다.

---

## 공통 규칙

| 항목 | 값 |
|------|-----|
| 렌더링 | 전신 스토리북 몬스터 렌더링 |
| 방향 | 좌측 대각선 ↖ |
| 캔버스 | 2:3 세로형 (1024×1536 생성) |
| 게임 해상도 | 1080p (1920×1080) |
| 명암 | 상체 디테일 집중 + 하체 읽히는 감쇠 |
| 외곽선 | 리전 팔레트 틴트 니어블랙 |
| 텍스처 | 종이 질감 5~8% |
| 배경 | 순백 `#FFFFFF` 추출용 |
| 톤 | 공포보다 패턴 인지가 우선 |
| 속성 표현 | 포인트 방식 (특정 부위에 시각적 단서) |

## 고대 수목군주 (BOSS_F01) — Phase별 비주얼

### Phase 1: 고요한 수호자 (HP 100%~50%)

| 항목 | 값 |
|------|-----|
| 실루엣 | 나무껍질로 덮인 인간형, 직립 자세 |
| 표면 | 나무껍질 피부 + 이끼/덩굴 장식 |
| 얼굴 | 나무껍질로 덮임, 나뭇결 속 희미한 앰버(`#D4A574`) 빛 눈 |
| 공격 수단 | 단일 뿌리 채찍 (땅에서 뻗어 공격) |
| 분위기 | 고요하고 위엄 있는 숲의 수호자 |
| 크기 | T3, 캔버스 85% |

### Phase 2: 깨어난 분노 (HP 50% 이하)

| 항목 | 값 |
|------|-----|
| 실루엣 | 하체 뿌리 팽창 + 상체 나뭇가지 확장 (더 거대해짐) |
| 표면 | 나무껍질 갈라져 내부 앰버(`#D4A574`) 발광 |
| 얼굴 | 강렬한 앰버 발광 눈 |
| 공격 수단 | 다수의 거대 뿌리 촉수 + 껍질 발광 충격파 |
| 분위기 | 깨어난 고대의 분노 |
| 특수 | 뿌리 속박 강화 + 경화 + HP 회복 |

## 관리 포인트

| 항목 | 기준 |
|------|------|
| 방향 | 좌측 대각선 ↖ |
| Tier | T1=2등신 60%, T2=2.5등신 70%, T3=3등신 85% |
| 속성 식별 | 포인트 방식으로 특정 부위에 시각적 단서 |
