# 배경 설계도 v5.0

> **최종 수정일**: 2026-03-15

## 목적

- 장소감, 깊이감, 전투/비전투 씬 역할 차이를 관리한다.

---

## 공통 규칙

| 항목 | 값 |
|------|-----|
| 해상도 | 1920×1080 (1080p, 16:9) |
| 텍스처 | 은은한 종이 질감 |
| 원칙 | 배경은 유닛과 카드보다 앞서 눈에 띄면 안 된다 |
| 중앙 | 카드/UI 공간을 위해 개방 유지 |
| 리전감 | 같은 리전 내 색 온도와 공기감 이어짐 |

---

## 2-Tier 시스템

### Tier 1 — 맵/이벤트/상점

| 항목 | 값 |
|------|-----|
| 스타일 | 레이어드 실루엣 |
| 구성 | 3~5 깊이 레이어 |
| 중앙 | 앰버 글로우 + 그라데이션 |
| 전경 | 강한 비네트, 나무/건물 실루엣 |
| 장면 수 | 리전당 2장 (낮/황혼) |

### Tier 2 — 전투

| 항목 | 값 |
|------|-----|
| 스타일 | 전경 실루엣 + 중경 스토리북 디테일 |
| 구성 | 전경 프레임 + 중경 일러스트 + 종이 질감 오버레이 |
| 장면 수 | 리전당 1장 base |
| 어둡기 변형 | 런타임 오버레이로 3단계 처리 |

### Tier 2 — 전투 배경 (신규 제작 필요)

| 항목 | 값 |
|------|-----|
| 장면 | 숲 속 공터 |
| 상단 | 부분적으로 열린 나뭇가지 캐노피 (빛 유입) |
| 좌우 | 고목 기둥 + 덤불 실루엣 |
| 바닥 | 낙엽 + 이끼 |
| 중앙 | 개방 (카드/UI 공간) |
| 팔레트 | 앰버/올리브/바크브라운 (숲 리전) |

## 어둡기 3단계 (런타임 오버레이)

| 단계 | 적용 라운드 | 분위기 | 구현 방법 |
|------|-----------|--------|----------|
| 1단계 | R1~3 | 오후의 따뜻한 숲 | 기본 밝기 (오버레이 없음) |
| 2단계 | R4~5 | 석양/황혼 | 앰버 강화 + 그림자 15~25% 어둡게 |
| 3단계 | R6~8 + 보스 | 어두운 황혼~초저녁 | 블루 언더톤 + 30~45% 어둡게 |

> 구현: 기본 1장 생성 후, 게임 엔진에서 색상 필터/오버레이로 어둡기 단계 처리.
