## 2. 반드시 지켜야 할 감정 축

| 축 | 유지할 감각 | 피해야 할 감각 |
|----|-------------|----------------|
| 분위기 | 아름다운 긴장감, 모험의 설렘, 잔잔한 위협 | 공포, 혐오, 고어, 과잉 우울 |
| 캐릭터 | 희망, 소년/소녀성, 인간적인 온기 | 성숙 과잉, 냉정함, 영웅 과장 |
| 몬스터 | 불길함, 경계심, 패턴 읽기의 명확성 | 혐오감, 혐오 디테일, 혼탁함 |
| 프레임/UI | 기능적 안정감, 조용한 고급감 | 장식 과잉, 판타지 과장, 노이즈 |
| 배경 | 세계의 깊이, 장소감, 감정의 온도 | 정보 과밀, 텍스처 과잉, 시선 분산 |

## 3. 플레이 관점 에센스

### 3-1. 전투 가독성

- 플레이어는 1초 안에 적의 역할과 위협도를 읽을 수 있어야 한다.
- 캐릭터는 감정 이입의 중심이므로 얼굴, 눈, 실루엣, 주무기가 먼저 읽혀야 한다.
- 몬스터는 공포보다 패턴 인지가 우선이다. 독이면 독주머니, 가시면 가시 윤곽, 경화면 단단한 면 분리가 먼저 보여야 한다.

### 3-2. 카드 게임다움

- 프레임은 세계관 장식이 아니라 정보 구조의 일부다.
- 장식성보다 분류력과 위계가 먼저다.
- 플레이어/일반/정예/보스 프레임은 한눈에 위협 단계가 갈려야 한다.

### 3-3. 세계 일관성

- 캐릭터, 몬스터, 배경, UI는 서로 다른 화풍처럼 보이면 안 된다.
- 같은 재료와 같은 공기에서 만들어진 세계처럼 보여야 한다.
- 이 일관성은 색보다도 질감, 광원, 명암 감쇠, 선의 성격에서 나온다.

## 4. 시각 판단 체크포인트

| 판단 항목 | 질문 |
|-----------|------|
| 얼굴 | 표정만 보고 감정 축이 읽히는가? |
| 실루엣 | 축소해도 캐릭터와 몬스터의 정체가 읽히는가? |
| 명암 | 하반신이 죽지 않으면서도 상체 중심이 유지되는가? |
| 색상 | 리전/클래스/속성의 구분이 섞이지 않는가? |
| 프레임 | 장식보다 기능이 먼저 읽히는가? |
| 배경 | 카드와 유닛을 받쳐주되 경쟁하지 않는가? |

---

## 5. 우선순위 원칙

1. **가독성**이 장식보다 우선한다.
2. **세계 일관성**이 개별 에셋의 개성보다 우선한다.
3. **기획 정합성**이 멋있는 변형보다 우선한다.
4. **실행 프롬프트 정합성**이 설명 문구보다 우선한다.
